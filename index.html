MCP & Connector Integration Layer

MetaFlow · Yukosa
Agentic AI

A pure-MCP system letting a no-code platform connect any remote MCP server on demand — via a generic plugin in the agent's tool-orchestration layer, reusing the existing request contract with no new API surface.

  • Full OAuth 2.0 (Dynamic Client Registration + PKCE) with static-client fallback, proven end-to-end across Slack, Jira, GitHub, Notion & Linear; live tool discovery (19–27 tools/server) with confirmation-gating on destructive actions
  • Hardened 8+ enterprise connectors with automatic token refresh across 11 — a shared 401 detector refreshes & retries before the agent ever sees a failure; encrypted-at-rest credentials, per-user/org scoping, vendor-side revocation
  • Two-layer prompt-injection guardrail + Meta Prompt Guard (86M classifier) tuned to jailbreak-only: 0 false positives, 8/10 attacks caught
  • In-agent file tools generating Word/Excel/PPT/PDF with 14 chart types and an exact-totals aggregation engine (computed, not model-guessed)
